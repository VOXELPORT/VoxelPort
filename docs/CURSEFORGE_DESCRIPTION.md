**Description:**

```
Open your Minecraft world or Fabric server to friends in one click. No port forwarding, no account.

Open your world to LAN, press Esc, then "Open to VoxelPort". The address is copied for you (play.voxelport.in:<port> in India or play-eu.voxelport.in:<port> in Europe, whichever relay is closer). Friends join from normal Minecraft and do not need the mod. On a Fabric server, run /voxelport start.

Needs an external service. The mod connects to VoxelPort's relay servers (relay.voxelport.in and eu.voxelport.in) to give you a public address. It does not work offline.

REQUIREMENTS
Minecraft 26.1, 26.1.1, 26.1.2, 26.2 or 26.3, Fabric Loader 0.18.6+, Java 25+. Only the host installs the mod.

COMMANDS
/voxelport start [port], /voxelport status, /voxelport stop (also /voxel and /vp; operator level 2).

PRIVACY
Stored on your computer: a random device token. Sent to the relay: that token, the mod name and version, and your game's network traffic while you share, which is passed on and never inspected. Not collected: passwords, email, chat, inventory, world data or analytics. Full policy: https://voxelport.in/legal

NOTES
Your game must stay open while friends play. The relays are run by one student with no uptime guarantee: https://voxelport.in/status

Source code (MIT): https://github.com/VOXELPORT/VoxelPort
Not affiliated with Mojang or Microsoft.
```
